# Управление процессами и проектами

Учебник для подготовки к собеседованиям на Project Manager, Delivery Manager и TPM: **18 разделов, 129 тем, семь подробных System Design-разборов и банк из 100 вопросов с 300 вариантами ответов**. Чтение, поиск по всему содержимому, фильтры уровня, подсказки и отметки работают без интернета. Приложение сохраняет прогресс и место чтения.

**Скачайте проект → откройте в Xcode → выберите свою Team и iPhone → нажмите Run.** Публикация в App Store и платная подписка разработчика для личной установки не требуются.

## Установить на свой iPhone

Понадобятся **Mac, полный Xcode, Apple Account, iPhone с iOS 16 или новее и кабель**. Xcode должен поддерживать установленную на телефоне версию iOS. Проект проверен с Xcode 26.2; Node.js и Homebrew для установки не нужны. Xcode автоматически получает закреплённый ONNX Runtime; для необязательной подготовки нейросетевых моделей нужен Python 3.

1. На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив на Mac. Можно также клонировать репозиторий через Git.
2. Откройте **Xcode** хотя бы один раз и завершите его начальную настройку.
3. В распакованной папке дважды нажмите **`Start.command`**. Он проверит Xcode, создаст личный Bundle Identifier и откроет проект. Если запуск файла недоступен, используйте Terminal из этой папки:

   ```bash
   bash scripts/setup.sh
   ```

4. В **Xcode → Settings → Accounts** добавьте свой Apple Account. Затем выберите синий проект слева → **TARGETS → InteractiveBook → Signing & Capabilities**. Оставьте **Automatically manage signing** включённым и выберите свою **Team / Personal Team**.
5. Подключите разблокированный iPhone, подтвердите **«Доверять этому компьютеру»**. При запросе включите **Developer Mode** в настройках телефона и выполните перезагрузку.
6. В верхней панели Xcode выберите **свой iPhone**, а не симулятор или `Any iOS Device`. Нажмите **▶ Run / ⌘R**. После установки учебник появится на телефоне; кабель можно отключить.

**[Подробная инструкция, обновление и решение ошибок → docs/INSTALL-IOS.md](docs/INSTALL-IOS.md)**

У бесплатной Personal Team профиль подписи действует **7 дней**. После истечения срока приложение нужно повторно собрать и установить через Xcode; удалять его не нужно. [Правила Apple](https://developer.apple.com/help/account/basics/about-your-developer-account)

Через Git проект можно скачать так:

```bash
git clone https://github.com/siliconbaba/syllabus.git
cd syllabus
bash scripts/setup.sh
```

## Что автоматизировано

| Команда | Действие |
| --- | --- |
| `bash scripts/setup.sh` | Проверяет Xcode, создаёт личный Bundle ID, открывает проект |
| `bash scripts/setup.sh --check` | Проверяет готовность Xcode без изменения файлов |
| `bash scripts/setup.sh --no-open` | Подготавливает настройки без открытия Xcode |
| `bash scripts/install-device.sh --list` | Показывает устройства, известные Xcode |
| `bash scripts/install-device.sh --device DEVICE_ID` | Повторно собирает, подписывает, устанавливает и запускает приложение |
| `bash scripts/check.sh` | Собирает приложение для симулятора и запускает проверки WebKit |

Команда установки на устройство рассчитана на **уже выполненную первую установку через Xcode**: аккаунт добавлен, Team выбрана, телефон зарегистрирован и доверие подтверждено. `DEVICE_ID` берётся из вывода `--list`. Скрипт не выбирает телефон сам. Для проверки настроек без установки добавьте `--dry-run`.

Личный Bundle ID хранится в `Config/Local.xcconfig`, исключённом из Git. Скрипт не меняет его при повторном запуске. Выбранная в интерфейсе Xcode Team может сохраняться в файле проекта; порядок обновления описан в подробной инструкции. Сохраните этот файл при скачивании обновлений — постоянный Bundle ID нужен, чтобы обновлялось то же приложение с тем же прогрессом.

## Слушать учебник

Откройте тему и нажмите **«Слушать»**. Нижняя панель управляет паузой, продолжением, остановкой, переходами по блокам и скоростью. По умолчанию используется локальный системный TTS iOS. Дополнительно доступен нейросетевой Xenia при подготовленных моделях — [инструкция сборки](docs/SILERO_BUILD.md). Оба режима без серверов и API-ключей. Чтение поддерживает фон и блокировку экрана; читаемый абзац подсвечивается.

[Как работает аудиочтение, выбор голоса и ограничения → docs/AUDIO.md](docs/AUDIO.md)

## Что внутри

- SwiftUI + WKWebView; весь учебник включён в приложение.
- Удобное оглавление, светлая/тёмная тема, фильтр уровня.
- Крупные элементы управления и таблицы с отдельной горизонтальной прокруткой.
- Сохранение изученных тем, чек-листов, раскрытых ответов и места чтения.
- Учебник не отправляет прогресс на сервер; автоматической синхронизации между устройствами нет. Внешние ссылки открываются отдельно и требуют сети.

Это независимый учебный проект, не официальное приложение Яндекса.

## Разработка и проверки

Схема `InteractiveBook` уже включена в репозиторий. Файлы интерфейса находятся в `InteractiveBook/WebContent`, нативная оболочка — в `App.swift` и `BookView.swift`. ONNX Runtime 1.24.2 закреплён в Swift Package Manager; большие модели исключены из Git.

Сборка для симулятора и изолированные проверки WebKit запускаются командой `bash scripts/check.sh`. Откроется временное тестовое окно; данные установленного учебника не затрагиваются.

Проверены: сборка в Xcode 26.2, запуск в симуляторе iPhone 17 Pro / iOS 26.3, поиск без увеличения масштаба, положение шапки, восстановление темы; проверки WebKit при ширине 390 и 320 px для фильтров, раскрытия ответов, таблиц и сохранения состояния. Подпись и установка на физический iPhone должны быть выполнены владельцем телефона со своей Team.

## Сохранённое

Выделите текст в теме стандартным выделением iOS и нажмите появившуюся кнопку **«Сохранить»**. Кнопка **«Сохранённое»** в шапке открывает персональную коллекцию. Нажатие на фрагмент возвращает к источнику с краткой подсветкой; свайп влево удаляет его. Повторное сохранение того же фрагмента не создаёт дубль. Всё хранится на устройстве отдельно от прогресса, без сети и синхронизации.

### Жесты навигации

После перехода к другой теме или сохранённой цитате проведите вправо от левого края области чтения, чтобы вернуться к предыдущему месту. Тот же переход доступен кнопкой «Назад к чтению» в оглавлении. Оглавление закрывается свайпом влево. История действует в текущем сеансе приложения; простая прокрутка не создаёт записей. На таблицах, при выделении текста и при касании несколькими пальцами жест назад не срабатывает.

## Источник контента

Канонический учебник — InteractiveBook/WebContent/index.html. BookView загружает его напрямую из локальной папки WebContent в bundle; этапа копирования из другого HTML или сборки контента нет. Дополнительные стили находятся в mobile.css и content.css, поведение чтения — в reader.js. Все ресурсы схем встроены в HTML как SVG, внешние библиотеки для отображения не нужны.

Проверка интеграции контента: python3 scripts/check_content.py (также входит в scripts/check.sh). Tests/content-manifest.json хранит контрольные суммы полного содержимого 100 исходных вопросов и всех трёх вариантов, распределение исходных материалов System Design и прежние ключи состояния раскрывающихся блоков.

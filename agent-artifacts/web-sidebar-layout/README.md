# Веб-версия с боковым оглавлением

Пересобрана из текущего InteractiveBook/WebContent через scripts/build_web.py.

- Оглавление занимает отдельную колонку, не перекрывает текст.
- Текст остаётся интерактивным; клики по нему не закрывают меню.
- Выбор темы сохраняет меню открытым.
- Закрытие кнопкой, повторным нажатием на меню или Escape.
- При изменении ширины чтения сохраняется текущая тема и смещение внутри неё.
- Изменение включается только маркером data-standalone-web, который добавляет сборщик HTML. В нативном документе маркера нет.

Проверки WebKit: PASS на ширине 390 и 1280 — отдельные колонки, доступность текста, сохранение позиции, переход к теме, явное закрытие. Результаты: web-check-390.txt, web-check-1280.txt. Сценарий ожидает реальные animation frames, а не только таймер.

Проверка содержимого сборщиком: PASS (129 тем, 100 вопросов, 300 вариантов).
Git diff whitespace validation: PASS.
Нативная регрессия 1280: PASS (native-regression.txt). Нативная регрессия 390 оказалась нестабильной: в отдельных запусках падали проверки восстановления/позиционирования; сохранён последний результат native-regression-390.txt. Полный PASS этой проверки не заявляется.

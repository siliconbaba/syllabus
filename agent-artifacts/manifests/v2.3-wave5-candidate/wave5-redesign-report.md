## TC-236 — middle / t-9-3

Why lower-level reasoning is insufficient: Простое деление CoD на размер уже выполнено и даёт неверную рекомендацию: нужно сопоставить время завершения и нелинейную потерю по общему горизонту.

Source: критичность по времени растёт по мере приближения дедлайна; полный topic/excerpt в source-grounding-wave5.json. Числа и ограничения сценария авторские.

Semantic distinction: TC-058/059 имеют одинаковую длительность и постоянную CoD; TC-074 ждёт независимый шлюз. Здесь обе инициативы готовы к старту, а статический CD3 проигрывает из-за скачка денежной потери во времени; обязательного mandatory-фильтра нет.

Runtime evidence:
- cost-of-delay: Сравнить360 и170 по двум порядкам, включая разовую потерю окна, не меняя произвольно оценки.

## TC-264 — senior / t-3-3

Senior release lead разбирает неуспешную репетицию blue-green: схема совместима, HTTP-трафик вернулся на blue, но уже запущенные фоновые операции green продолжают менять состояние по новой семантике.

Decisive facts:
- Обе версии читают и пишут общий совместимый формат; сверка данных чистая. Операция состоит из HTTP-приёма и длительного фонового завершения; переключатель HTTP не останавливает её уже запущенную вторую часть.

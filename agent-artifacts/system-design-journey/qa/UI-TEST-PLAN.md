# Проверки в настоящем браузере

Статус: **NOT_RUN**. Известные ограничения WebKit/XPC и file URL не обходились. Ни статический анализ, ни Node VM не подтверждают внешний вид или доступность в реальном браузере. Скриншоты не создавались.

При доступном разрешённом браузере:

1. Проверить ширины 320, 390, 768 и 1440 px: меню, заголовки, панели, SVG и таблицы; горизонтальный scroll только локальный у широкого материала.
2. Пройти главы 01, 08, 16, 24, 32 мышью и клавиатурой. Проверить видимый focus, порядок Tab, раскрытие пояснений, переходы вперед/назад.
3. Дать верный и неверный checkpoint-ответ. Убедиться, что сообщение читается, теория не закрыта и ответ после перезагрузки восстановлен.
4. Записать заметку с кириллицей, переносом строки и буквальным `<script>`. Добавить закладку, решение; перезагрузить и экспортировать. Сравнить все пользовательские данные.
5. Проверить страницу при недоступном localStorage и без сети: текст, схемы и экспорт остаются доступны; источники открываются только по явному переходу.
6. Подготовить старые ключи sd-course-v1/v2 с прогрессом. Открыть новый курс: старые завершения не становятся новыми, старые значения не изменяются.
7. Проверить все восемь миров атласа и переход из экспедиции; проверить шрифт схем и captions на телефоне, screen reader labels и live feedback.

Результаты каждой проверки должны ссылаться на фактически запущенный браузер и viewport. До этого статус остаётся NOT_RUN.

# Тренажёр — Slice 2

## Реализация

Продолжение, смешанный набор 5/10/15/все, раздел/тема и повтор ошибок используют один TrainerView session/review/summary. Новая незавершённая попытка заменяет старую только после подтверждения. Завершённая хранится до старта следующей; отдельного архива попыток нет.

Кейсы выбираются случайно без повторов, варианты не перемешиваются. Набор, порядок и содержимое сохраняются в snapshot Attempt. requiredLevel и прочие диагностические метаданные в отборе и результате не участвуют. Итог считает только ответы с isBest и показывает число исправленных ошибок для mistakes mode.

## Состояние и миграция

- TrainerSession: kind, title, optional sectionID/topicID. В старых snapshots отсутствует; отображается как «Учебная тренировка».
- TrainerAttempt: прежний snapshot и фаза плюс session и resolvedIDs текущей сессии.
- TrainerProgress: словарь по testId, revision последнего отвеченного кейса, answers/errors, lastErrorAt, lastAnsweredAt, resolved.
- Подтверждение атомарно записывает Attempt и Progress в Application Support/Trainer/state.json. Повторный confirm/review не увеличивает счётчики. При ошибке записи новое состояние не публикуется.
- schemaVersion 1 читается и явно мигрирует в 2. Оригинал сохраняется в state.json.slice1-backup; snapshot и позиция не меняются. Подтверждённые ответы имеющейся старой попытки переносятся в Progress один раз. Старые удалённые попытки восстановить невозможно. Точное время старого ответа неизвестно: используется completedAt либо startedAt.
- Неизвестная версия/повреждение не перезаписываются автоматически, запуск новой попытки блокируется до явного полного reset.
- Reset текущей тренировки удаляет только незавершённую Attempt. Полный reset удаляет Attempt, весь Progress и резервную копию миграции. Данные учебника, Saved и TTS не затрагиваются.

Ошибка — подтверждённый !isBest. Правильный ответ закрывает её только в mistakes mode; resolved-запись остаётся. Новая ошибка снова открывает запись. Повтор ошибок берёт актуальную редакцию из банка по testId; отсутствующие в банке записи пропускаются, история сохраняется. Число доступных для повторения ошибок учитывает текущий банк. Пересмотр редакции кейса сам по себе не отменяет resolved: автоматическая политика пересмотра результатов пока не вводилась.

## Каталог тем

TrainerContent/topics.json содержит только ID и названия разделов/тем из оглавления. Runtime читает bundled JSON, HTML не парсит. UI выводит только разделы и темы, для которых есть кейсы. Все 25 текущих кейсов покрыты каталогом. Для раздела/темы до 15 кейсов стартуют все, свыше 15 доступен выбор размера.

Обновление после изменений оглавления:

```sh
python3 scripts/build_trainer_catalog.py
python3 scripts/build_trainer_catalog.py --check
bash scripts/check.sh
```

Проверка каталога включена в check.sh и обнаруживает неизвестный topicId или устаревшие названия. Изменение формулировок cases.json не требует правок UI.

## Проверки

TrainerTests: загрузка/метаданные банка; mixed 5/10/15/all; уникальность и сохранённый порядок; фильтры раздела/темы; ошибочный ответ и повторная ошибка; resolved и сохранность истории; исключение resolved/удалённых кейсов; актуальная revision для повторения и неизменность активного snapshot; оба reset; реальный JSON schemaVersion 1 без новых полей, резервная копия, однократность миграции; неподдерживаемая версия и ошибки сохранения.

Полный scripts/check.sh: сборка Simulator, контент, WebKit 320/390/1280, Trainer, Speech, Engine, Saved и регрессии произношения.

Ручная приёмка, iPhone 17 Pro / iOS 26.3 Simulator, 2 октября 2026:

1. Установка поверх Slice 1 сохранила завершённую попытку на 25 кейсов; её 22 ошибки появились в Progress.
2. После очистки тестовых данных запущена mixed-5: TC-022, TC-008, TC-015, TC-019, TC-004. Первые два ответа ошибочные.
3. Перезапуск на review третьего кейса. «Продолжить» восстановило тот же разбор; сохранённый JSON до/после restart/resume полностью совпал.
4. Завершение mixed: итог 3 из 5 и все пять разборов.
5. Повтор двух ошибок: TC-022 решён верно, TC-008 снова неверно. Итог: исправлена 1, осталась 1. На диске TC-022 resolved=true/errors=1, TC-008 resolved=false/errors=2.
6. Раздел «Основы управления проектами»: темы 2.4 и 2.6 по два кейса; весь раздел запускает 4.
7. Выбор темы при активной попытке запросил подтверждение. Отмена сохранила раздел; подтверждение запустило 2 кейса темы 2.4.
8. Reset текущей попытки сохранил весь Progress (проверено полным сравнением). На входе осталась одна ошибка.
9. Отмена полного reset сохранила ошибку. Подтверждение очистило результаты, экран ошибок показал «Ошибок для повторения пока нет».
10. Возврат в учебник сохранил тему 10.8 и прежнюю позицию чтения.

## За пределами Slice 2

Нет диагностики, уровней, confidence, профилей областей/паттернов, DiagnosticHistory, адаптивной сложности, рекомендаций, UI парных сценариев, shuffle вариантов, TTS тренажёра, аккаунта/синхронизации и новых зависимостей. История resolved хранится, отдельного экрана аналитики нет. Сохраняется вопрос/фаза, а не точный scroll offset разбора.

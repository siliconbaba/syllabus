# Аудиочтение темы

Откройте нужную тему и нажмите **«Слушать»** рядом с отметкой «Изучено». Внизу появится панель: предыдущий блок, Play/Pause, Stop, следующий блок и скорость **0.8× / 1.0× / 1.2× / 1.5× / 2.0×**. В меню скорости откройте «Голос»: доступны автоматический выбор и все установленные ru-RU голоса с отметками Premium / Enhanced / Standard. Выбор сохраняется; если голос удалён, используется лучший доступный. При смене голоса текущий фрагмент продолжается с последней речевой позиции.

Читается выбранная тема, начиная с заголовка. После её окончания воспроизведение останавливается. Переход в другую тему останавливает старое чтение; для новой темы снова нажмите «Слушать». Изменение фильтра уровня или раскрытых ответов останавливает чтение, чтобы старая очередь не продолжала озвучивать уже скрытый текст.

## Какой текст читается

Текст берётся из текущей страницы: заголовки, абзацы, списки и строки таблиц. Учитывается фильтр уровня. Закрытые подсказки и ответы не читаются — откройте нужные блоки перед запуском. Навигация, кнопки, скрытые элементы, URL, иконки и блоки кода исключаются. Технические сокращения нормализуются только для речи: например API, SQL и CI/CD; видимый текст учебника не меняется.

Подсвечивается текущий абзац или смысловой блок. Автопрокрутки за голосом нет: это позволяет листать материал без неожиданных прыжков. Для длинного абзаца может потребоваться несколько речевых фрагментов, с общей подсветкой абзаца.

## Голос и офлайн-работа

В системном режиме используются `AVSpeechSynthesizer` и установленные голоса iOS. Приложение не отправляет текст на сервер и не требует API-ключей. Из доступных обычных русских голосов выбирается `ru-RU`, приоритет отдаётся более высокому качеству. Конкретный идентификатор голоса не зашит в приложение. При отсутствии русского голоса используется доступный системный вариант с сообщением пользователю.

Для лучшего звучания заранее загрузите улучшенный русский голос в настройках **Универсального доступа** iPhone, в разделе чтения/речи. Названия разделов зависят от iOS. Скачивание голоса выполняется средствами iOS; после загрузки он доступен для локального чтения. Приложение не загружает сторонние речевые модели. Множители скорости задают относительную скорость системного TTS, а не гарантированную длительность аудиофайла.

## Системный и нейросетевой режимы

В меню скорости откройте **Озвучивание → Системный / Нейросетевой**. Выбор сохраняется; по умолчанию используется системный голос. При переключении чтение продолжается с начала текущего смыслового блока.

**Нейросетевой · Xenia** работает полностью на устройстве, без сети и Python. В сборку нужно заранее включить проверенные модели — около **220 МБ**; инструкция для сборки: [SILERO_BUILD.md](SILERO_BUILD.md). Приложение само их не скачивает. Первый запуск показывает «Подготовка нейросетевого голоса…», последующие фрагменты готовятся заранее. Скорость меняет темп готового звука без изменения высоты голоса. Пауза сохраняет позицию звука.

При недоступных или повреждённых моделях приложение сообщает об этом и возвращается к системному голосу с начала текущего блока. Текст не пропускается. При нехватке памяти нейросетевое чтение приостанавливается, ресурсы освобождаются; его можно запустить снова.

## Блокировка экрана и системное аудио

В проекте включён Background Mode `audio`, используется `AVAudioSession` с категорией `playback` и режимом `spokenAudio`. Очередь темы хранится в Swift, поэтому продолжение речи не зависит от выполнения JavaScript в фоне.

Доступны системные Play/Pause, Stop и переходы между блоками через Now Playing. При звонке/аудиопрерывании чтение ставится на паузу и возобновляется только если это разрешила система и пользователь не остановил его. При отключении наушников чтение приостанавливается. При паузе и остановке аудиосессия освобождается, чтобы другие приложения могли продолжить звук.

Скорость сохраняется между запусками. Последняя тема и номер аудиоблока также записываются локально, но автоматическое возобновление с этой закладки пока не включено: кнопка «Слушать» начинает выбранную тему сначала.

## Архитектура

- `InteractiveBook/WebContent/audio-reader.js` извлекает структурированные блоки из DOM и подсвечивает их. Учебник не копируется вручную в Swift.
- `SpeechTextProcessor.swift` содержит расширяемый словарь произношений, удаление URL и разбиение слишком длинных абзацев.
- `SpeechReaderManager.swift` — наблюдаемый менеджер с одним выбранным движком, очередью фрагментов, защитой от устаревших callback, управлением аудиосессией и системными командами.
- `SpeechControls.swift` — компактная SwiftUI-панель.
- `BookView.swift` — безопасный обмен сообщениями только с основной страницей локального WebView, извлечение темы и подсветка.

Ключи `speech.*` в UserDefaults отделены от существующего прогресса `bookState`.

## Проверки

`bash scripts/check.sh` собирает приложение и запускает изолированные проверки WebKit и Swift: исключение скрытых элементов/кода/UI, нормализация, разбиение, пауза, продолжение, смена скорости, быстрые команды, устаревшие callback, конец темы, прерывания и отказ аудиосессии.

Симулятор не заменяет проверку качества конкретного голоса, реального входящего звонка, Bluetooth-наушников и фонового поведения на физическом iPhone. Для такой проверки используйте обычную установку через Xcode со своей Team. Минимальная версия приложения остаётся iOS 16.

## Quality-pass TTS

Синтез идёт по естественным предложениям с прежней подсветкой блока. Только предложение длиннее 1200 символов делится по словам (без пробелов — по безопасным границам Unicode). Паузы `postUtteranceDelay`: внутри абзаца 0.10 с, конец абзаца 0.30 с, заголовок 0.45 с, элемент списка 0.20 с. `preUtteranceDelay = 0`, `pitchMultiplier = 1.0`. Текст ради пауз не меняется.

Базовая скорость 1× — 0.46; 0.8× / 1.2× / 1.5× / 2× дают 0.368 / 0.552 / 0.69 / 0.92 с ограничением системным диапазоном. Это выбранная спокойная стартовая настройка для учебника, субъективный комфорт зависит от голоса; коэффициенты не гарантируют точного ускорения длительности.

В Debug журнал выводит все ru-RU голоса (name, identifier, quality, selected), а также `Automatic speech voice:` и `Selected speech voice:`. Отсутствие Enhanced/Premium в Simulator нормально. Автоматический выбор сохраняет приоритет Premium > Enhanced > Standard и исключает специальные Personal/Novelty голоса; ручной список показывает все ru-RU варианты.

## Слушать с выбранного абзаца

Выделите слово или фрагмент нужного абзаца и нажмите «Слушать отсюда» рядом с «Сохранить». Чтение начнётся с начала этого смыслового блока и продолжится до конца темы. Работает с обоими движками; прежняя очередь и подготовленный звук отменяются.

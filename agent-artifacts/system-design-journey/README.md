# Системы: путь архитектора

Полностью переработанный курс проектирования систем для опытных PM, Delivery и Release Manager. Основной маршрут — развитие вымышленного сервиса «Северный маршрут»; параллельно работает атлас архитектурных миров и сравнительные экспедиции.

## Устройство

- 32 главы в восьми сюжетных арках: от первого заказа и конкурентной записи до геосервисов, распределённых данных, медиа, ML/AI и миграций.
- В каждой главе — подробная теория, авторские точные SVG, разобранный пример, экспедиция в другой бизнес, сравнение решений с последствиями, короткое упражнение и два вопроса с объяснениями после подтверждения.
- Атлас восьми миров: деньги, ограниченный ресурс, поиск, геосервисы, совместное состояние, медиа, телеметрия и SaaS. Карта 14 типов бизнеса показывает сочетание этих механизмов.
- Поиск по содержанию, словарь, свободная навигация, заметки, закладки, ручные отметки прочтения, сохранение позиции и экспорт портфеля.

Длительность не назначена искусственно. Интерфейс показывает фактический объём текста и главы; скорость чтения и разбора схем зависит от пользователя. Выбор решения сохраняется как сравнение альтернатив, а опорная история остаётся общей. Нет штрафов, обязательных пауз или блокировки следующей главы.

## Где править и как собрать

Каноническое содержание — четыре chapters-*.json, atlas.json, market.json и паспорта истории story-stages.json. Интерфейс — template.html. Авторский источник паспортов — write_atlas.py; он воспроизводит atlas.json. DESIGN.md объясняет методологию, источники программ и границы исследования. CONTENT-CONTRACT.md фиксирует структуру глав и первоначальную карту покрытия.

Из корня syllabus:

```sh
python3 agent-artifacts/system-design-journey/build.py
python3 agent-artifacts/system-design-journey/qa/check_content.py
node agent-artifacts/system-design-journey/qa/logic.test.cjs
python3 agent-artifacts/system-design-journey/qa/check_offline.py
cp agent-artifacts/system-design-journey/system-design.html InteractiveBook/WebContent/system-design.html
python3 scripts/check_content.py
python3 scripts/build_web.py --output agent-artifacts/system-design-journey/web-preview/index.html
```

Сборка не подменяет отсутствующие главы заглушками. Она проверяет порядок, поля, HTML, SVG, источники, ссылки на миры и количество схем. Author SVG ID получают уникальные префиксы при генерации. Ресурсы отображения встроены в итоговый HTML. Внешние первоисточники требуют интернета; основное содержание и интерфейс — нет.

Активный ресурс мобильного приложения — InteractiveBook/WebContent/system-design.html. WebContent уже включён в bundle как папочный ресурс; новые записи в pbxproj не нужны. Веб-пакет содержит index.html основного учебника и system-design.html курса с взаимными относительными ссылками.

## Личные данные и старый курс

Состояние хранится в отдельном localStorage-ключе sd-journey-v3. Значения sd-course-v1, sd-course-v2 и прогресс основного учебника не перезаписываются. При экспорте прежние данные включаются отдельно в oldRaw, без выдуманного соответствия новым главам. Текст заметок экранируется при показе.

Экспорт открывает JSON в диалоге. В приложении используется копирование или системное выделение; скачивание Blob предусмотрено для обычного браузера. При недоступном хранилище показывается предупреждение, данные остаются в памяти до закрытия страницы. Автоматического импорта и межустройственной синхронизации нет.

Позиция сохраняется при прокрутке, переходе, pagehide, скрытии документа и через window.bookSavePosition для нативной оболочки. Кнопка в главе возвращает к сохранённой позиции. Ручная отметка прочтения не считается сертификацией знаний.

## Проверки и ограничения

Итоговые статусы находятся в qa/. Тест actual JavaScript с адаптером DOM не является браузерной проверкой layout. Нативная сборка, физический iPhone и визуальный прогон имеют отдельный статус; не следует выводить их успех из наличия CSS или исходников тестов.

Установленное приложение обновится только после пересборки и установки. Нативные аудиочтение и «Сохранённое» основного учебника к новому читателю пока не подключены. При переходе в курс текущее аудио основного учебника останавливается.

Предыдущая редакция находится в agent-artifacts/system-design как история работы; её тематические JSON не являются источником нового маршрута.

### Смысловые акценты

Редакторская карта reading-cues.json хранит точные фрагменты для всех 32 глав. reading_cues.py размечает определения, ключевые мысли, ограничения и термины без изменения текста; build.py валидирует итоговый HTML и сохранность исходного содержания. Для изменения акцентов правьте карту, затем запускайте build.py. Повторение терминов не подсвечивается автоматически.

### Редакторская приёмка от 8 ноября 2026

Замечания независимого аудита устранены адресно: согласованы примеры поиска, RAG и стоимости, отделены расчётные стенды от масштаба истории, уточнён русский язык и добавлены образцы ADR/runbook. В главах доступен «Паспорт этапа». Карта акцентов выбирает компактные определения и содержательные выводы; число акцентов зависит от главы. revise_cues.py — явная авторская карта выбора фрагментов для намеренного обновления reading-cues.json; обычная сборка её не запускает и использует только точные цитаты.

Итог, соответствие замечаниям и границы проверки: qa/editorial-2026-11-08/FIXES.md и RETEST.md. Исторический REPORT.md описывает состояние до исправлений. Визуальный прогон iOS и повторная нативная сборка после этих HTML/CSS-изменений не выполнены.

### Иллюстрированная история

Восемь сцен открывают арки (главы01/05/09/13/17/21/25/29); четыре вставки стоят после первого раздела глав04/09/17/30. Это художественные сцены вымышленной компании; точные64SVG-схемы сохраняют отдельную техническую роль. Иллюстрации созданы генеративной моделью и хранятся в illustrations/. Карта размещения и доступные описания — illustrations.json.

Два PNG-листа встроены в HTML один раз каждый; CSS показывает нужную ячейку без повторного хранения пикселей и без изменения исходных изображений. Ядро не обращается к внешнему серверу. Фигуры имеют размеры, подписи, alt и отложенную загрузку; занимают место только в выбранных главах. Файл курса увеличился примерно примерно до13MB (UTF-8) из-за растровой графики. Проверки и пределы — qa/ILLUSTRATIONS.md.

### Увидеть механизм

В главах03/04/07/08/09/11/14/17/26/30 добавлены10объясняющих вставок,29SVG-кадров: пошаговые истории, разрез записи и сравнения моделей. В интерфейсе доступны одиночные схемы и показ всех кадров; сравнения не обозначены этапами развития. Контролы не анимируются и не меняют учебный прогресс. При печати показаны все кадры. Источники — visual-explainers-a/b.json и visual-explainers.js; всё встраивается сборщиком. Проверка: python3 qa/check_visual_explainers.py; подробности — qa/VISUAL-EXPLAINERS.md.

### Небольшие вставки между абзацами — 9 ноября 2026

В16главах добавлены прозрачные рисованные виньетки: телефон с пакетом, карточки, ноутбуки, полка, передача посылки, конверты, чек, карта, велосипед, телефоны, картотеки, ключ, лампа, сканер, папки и калькулятор. Они стоят между абзацами, не обтекаются основным текстом и не заменяют определения или схемы. На мобильном изображение занимает88px по ширине, рядом остаётся короткая подпись.

Сборщик проверяет, что вставка находится между существующими абзацами; theoryWithSpots сохраняет исходную разметку текста. Виньетки встроены из единственногоPNG-листа и работают офлайн.

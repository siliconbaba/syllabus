# Сохранённое

MVP: стандартное выделение WebKit → contextual «Сохранить» → нативный список → переход к источнику / удаление свайпом. Полноценного редактора, тегов и облака нет.

`SavedExcerptStore` хранит Codable-массив под `saved.excerpts` в UserDefaults, отдельно от bookState. Запись содержит UUID, исходный визуальный текст, topicID/title, sectionTitle, anchor и дату. Пробелы нормализуются; TTS-преобразования не применяются. Повреждённый JSON не приводит к падению: оригинал сохраняется в recovery-ключе, пользователь видит сообщение.

`saved-excerpts.js` валидирует Range внутри одной видимой темы, исключает навигацию, UI, код, скрытые блоки и закрытые ответы. Действия «Сохранить» и «Слушать отсюда» появляются только при подходящем выделении. Payload фиксируется перед потерей фокуса; подтверждение сохранения приходит после обновления Swift store. Коллекция в JS не хранится. Native bridge принимает сообщения только от ожидаемого WKWebView, его controller и основной локальной страницы index.html; payload проверяется по типам, размерам и формату идентификаторов.

Anchor — общий с audio-reader semantic ID: topic ID и структурный путь элемента, независимо от фильтра и extraction. Старые saved anchors поддерживаются при чтении прежних записей. При обновлении учебника текст блока проверяется: если метка сдвинулась, выполняется поиск цитаты в той же теме. Если совпадения нет, открывается верх темы. Удалённая тема вызывает сообщение, сохранённая цитата остаётся. Для скрытого источника раскрывается ответ и при необходимости включается фильтр «Все». Временная `.saved-source` не пересекается с `.speech-current`.

Исходные тексты HTML не менялись. reader.js получил только доступ к существующей функции навигации. Аудиочтение останавливается при переходе из коллекции к источнику; остальные сценарии аудио не менялись.

Проверки: `bash scripts/check.sh` включает SavedTests (save/persistence/duplicates/delete/normalization/metadata/invalid payload/corrupt storage), WebKit smoke (selection → native save → anchor/text/topic fallback), существующие тесты страницы и обоих speech engines. Большие модели для этих новых unit/DOM-тестов не требуются.

## Проверка этой сборки

Полный check.sh прошёл, включая WebKit smoke при 390 и 320 px и прежние тесты аудиочиталки. Сборка установлена в Simulator; вход и пустое состояние проверены. Автоматический WebKit тест создаёт настоящий DOM Range, сохраняет через message handler в Swift и проверяет возвращение. Ручной сценарий iOS с двумя выделениями, удалением свайпом и перезапуском не подтверждён: доступный UI-инструмент не воспроизвёл долгое нажатие. Persistence/delete проверены отдельными Swift tests; это не подмена ручной проверки.

# Совместная разработка

Для установки учебника берите ветку `main` и следуйте [инструкции для iPhone](docs/INSTALL-IOS.md). Рабочая ветка команды — `develop`. В ней хранится промежуточный банк вместе с манифестами, замечаниями и результатами проверок.

Перед началом выберите разные задачи. Для работы над тренажёром откройте [текущее состояние](agent-artifacts/project-completion/CURRENT.md) и [очередь кейсов](agent-artifacts/project-completion/remaining-work.json). Договоритесь, кто берёт конкретные ID. Все связанные ситуации одного семейства лучше поручить одному автору, а проверку передать другому.

Создавайте личные ветки от актуальной `develop`. Например:

```bash
git fetch origin
git switch -c feature/trainer-batch-06 origin/develop
```

После коммита отправьте личную ветку и откройте pull request с базовой веткой `develop`. Для переноса в `main` подготовьте отдельный pull request от актуальной `main` с готовыми изменениями приложения, тестами и необходимыми ресурсами. Так черновые кейсы останутся доступны для работы в `develop`.

Проверки на Mac запускаются командой `bash scripts/check.sh`. В сеансе без графического интерфейса используйте `bash scripts/check.sh --headless`. Этот режим пропускает проверки интерфейса WebKit. Личный Bundle ID и Team храните в игнорируемом файле `Config/Local.xcconfig`.

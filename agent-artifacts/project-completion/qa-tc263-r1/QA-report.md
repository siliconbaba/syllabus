## Дефект, достаточный для отказа

**QA263-R1-B01 — Blocker: unique strongest not established.**

Не определено, насколько существенны оба последствия для ближайшей цели бизнеса. Независимые показатели не показывают существенного вреда — это снимает немедленную обязанность защитного отката, но не делает день команды автоматически выгодной инвестицией.

Два допустимых дополнения исходных фактов ведут к разному выбору: если поиск критичен для ближайшего обязательства, а возможный выигрыш карточки мал, откат с отложенной сверкой разумен; если перенос поиска допустим без значимых последствий, а недельная потеря функции существенна, сверка до отката сильнее.

# TC-131 и TC-132 · независимая проверка

Слепые решения до просмотра ключа — C и B. Для TC-131 полная проверка на арендованной машине стоит 27 с учётом обхода, ручная — 32, общий CI — 47. Для TC-132 ручной прогон стоит 32, написание тестов с прогоном на общем CI — 107, на выделенном — 117. Разработка перекрывается с очередью, стоимость работы при этом сохраняется. Один smoke в обеих ситуациях недостаточен. Расчёты, очерёдность частичных баллов и ключи совпали.

Смысл пары соответствует §3.9. Учащийся отделяет достаточность проверки от её затрат и складывает цену работы с потерями за время ожидания. Значения ставок и сроков явно заданы в условии. Буквальная подстановка одного фрагмента о готовности автоматизированного покрытия полностью уравнивает условия. Вопрос и четыре варианта совпадают. TC-003/004 проверяют достаточность самого основания для выпуска, TC-085 — время подготовки состояния. Здесь достаточность полного набора фиксирована, меняется цена способа его получить.

Открыто FDRP02-01. В C03 для TC-131 третья альтернативная стратегия требует провести ручной прогон и повторить его в общем CI до выпуска. В кандидате D предлагает выпуск после неполного smoke. Это разные основания для ошибки — лишнее подтверждение и недостаточное покрытие. Для TC-132 smoke присутствует в утверждённом пространстве. Проектное решение — согласовать одну запись F-DR-P02/TC-131 либо переработать соответствующую альтернативу с повторной приёмкой всей пары. Остальные содержательные проверки пройдены. К импорту всей пары вернуться после закрытия расхождения.

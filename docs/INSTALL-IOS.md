# Установка учебника на iPhone через Xcode

Эта инструкция рассчитана на человека, который скачал репозиторий впервые. Готовый общий `.ipa` не нужен: Xcode соберёт приложение и подпишет его вашим Apple Account для вашего телефона.

## 1. Подготовьте Mac и iPhone

- Нужен Mac с полным **Xcode** из Mac App Store или [Apple Developer](https://developer.apple.com/xcode/). Одних Command Line Tools недостаточно.
- iPhone должен работать на **iOS 16 или новее**. Для новой версии iOS может потребоваться более новый Xcode и подходящая версия macOS.
- Подготовьте Apple Account, кабель и доступ к интернету для первой настройки подписи. После установки учебник работает офлайн.
- Запустите Xcode. Самостоятельно прочитайте и примите лицензию, установите запрошенные компоненты. Скрипты проекта не принимают соглашения за вас и не устанавливают Xcode.

## 2. Скачайте и откройте проект

На GitHub: **Code → Download ZIP**, затем распакуйте архив. Не открывайте проект непосредственно внутри ZIP.

Дважды нажмите `Start.command` в корне распакованной папки. Он запускает `scripts/setup.sh` и оставляет окно с подсказками.

Если macOS не запускает `.command`, откройте Terminal, введите `cd ` с пробелом, перетащите в окно Terminal папку проекта и нажмите Enter. Затем выполните:

```bash
bash scripts/setup.sh
```

Скрипт выполняет только три действия:

1. Находит полный Xcode и проверяет его готовность. Глобальный выбор Xcode и системные настройки не меняются.
2. Создаёт файл `Config/Local.xcconfig` с уникальным личным Bundle Identifier, если файла ещё нет.
3. Открывает `InteractiveBook.xcodeproj`.

Пароль, Apple Account и сертификаты скрипт не запрашивает. Не удаляйте `Config/Local.xcconfig`: при следующей установке нужен тот же идентификатор.

**Без скрипта:** откройте `InteractiveBook.xcodeproj` двойным нажатием и в Signing & Capabilities замените `com.example.interactivebook` на уникальное значение, например `com.yourname.interactivebook2026`. Разрешены латинские буквы, цифры, точки и дефисы. После успешной установки сохраните это значение и не меняйте его при обновлениях.

## 3. Добавьте Apple Account и выберите Team

1. В меню **Xcode → Settings → Accounts** нажмите **+ → Apple Account** и войдите. Названия пунктов могут немного отличаться между версиями Xcode.
2. В левой панели проекта выберите верхний синий значок **InteractiveBook**.
3. В центральной области выберите **TARGETS → InteractiveBook**, затем **Signing & Capabilities**.
4. Оставьте **Automatically manage signing** включённым.
5. В поле **Team** выберите свой аккаунт. Без платной подписки он отображается как **Personal Team**.
6. Проверьте Bundle Identifier: после скрипта он начинается с `com.personal.interactivebook`. Дождитесь завершения подготовки подписи.

Аккаунт добавляется локально в Xcode. Публиковать сертификаты или настройки подписи в репозиторий не нужно. [Как Apple описывает выбор Team](https://help.apple.com/xcode/mac/current/en.lproj/dev23aab79b4.html)

## 4. Подготовьте телефон

1. Подключите iPhone к Mac кабелем и разблокируйте его.
2. На телефоне подтвердите **«Доверять этому компьютеру»** и введите код-пароль, если потребуется.
3. В Xcode откройте **Window → Devices and Simulators → Devices**. Дождитесь, когда телефон будет готов; первая подготовка может занять время.
4. На iPhone откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика / Developer Mode** и включите его. Подтвердите перезагрузку и повторное включение после перезапуска.
5. Если пункта Developer Mode нет, сначала подключите телефон к Xcode и попробуйте выбрать его для запуска приложения.

Режим разработчика включает сам владелец телефона. [Инструкция Apple по Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)

## 5. Соберите и запустите

1. В верхней панели Xcode рядом с кнопкой запуска выберите схему **InteractiveBook**.
2. В списке устройств выберите **название вашего iPhone**. `Any iOS Device` предназначено для сборки, а симулятор запускает приложение на Mac.
3. Нажмите **▶ Run** или **⌘R**.
4. Если macOS запрашивает доступ к ключу подписи в Keychain, проверьте, что запрос относится к Xcode/codesign, и подтвердите его самостоятельно.
5. Если телефон сообщает о недоверенном разработчике, следуйте указаниям iOS в **Настройки → Основные → VPN и управление устройством**, выберите свой профиль разработчика и подтвердите доверие, если такой пункт отображается.
6. Учебник откроется на телефоне. Для дальнейшего чтения запускайте его с домашнего экрана; постоянное подключение к Mac не требуется.

[Запуск приложения на устройстве — Apple](https://help.apple.com/xcode/mac/current/en.lproj/dev5a825a1ca.html)

## 6. Повторная установка одной командой

После первой успешной установки через Xcode можно пользоваться скриптом. Team должна быть сохранена в настройках проекта, а телефон — уже подготовлен и зарегистрирован.

Подключите и разблокируйте телефон. В Terminal из папки проекта:

```bash
bash scripts/install-device.sh --list
```

Скопируйте **Identifier** своего телефона из списка:

```bash
bash scripts/install-device.sh --device DEVICE_ID
```

Замените `DEVICE_ID` реальным значением, не именем этой переменной. Скрипт соберёт приложение, запросит обновление профиля подписи через ваш аккаунт Xcode, установит `.app` и запустит его. Он не удаляет приложение перед обновлением.

Если Team не задана, скрипт остановится с объяснением. Для проверки настроек без сборки/подписи/установки:

```bash
bash scripts/install-device.sh --device DEVICE_ID --dry-run
```

`--dry-run` не подтверждает доступность телефона или работоспособность подписи. При проблемах со входом в аккаунт или профилем откройте Xcode и снова выполните Run — графический интерфейс покажет необходимые действия.

## Срок подписи и сохранение прогресса

У бесплатной Personal Team профиль истекает через **7 дней**. Тогда снова подключите iPhone и выполните Run или команду повторной установки. Платная подписка не нужна для этого сценария личного использования. [Актуальные ограничения Apple](https://developer.apple.com/help/account/basics/about-your-developer-account)

Чтобы сохранить прогресс:

- Не удаляйте приложение с телефона перед обновлением.
- Используйте прежние Team и Bundle Identifier.
- При скачивании нового ZIP перенесите свой `Config/Local.xcconfig` в новую папку, затем выберите прежнюю Team в Xcode.
- При обновлении через Git файл `Config/Local.xcconfig` остаётся локальным. Если выбор Team изменил `project.pbxproj`, сохраните эти локальные изменения перед `git pull` либо запишите Team и повторно выберите её после обновления.
- Если Bundle Identifier был изменён вручную в Xcode, перенесите именно его: настройка target имеет приоритет над xcconfig.

Удаление приложения удаляет его локальные данные. Облачной синхронизации и резервного экспорта прогресса в этой версии нет.

## Частые ошибки

| Сообщение / ситуация | Что сделать |
| --- | --- |
| `xcodebuild requires Xcode` | Установить полный Xcode. Скрипт сам проверяет `/Applications/Xcode.app`; Command Line Tools недостаточно. |
| Лицензия Xcode не принята | Открыть Xcode и самостоятельно завершить первоначальную настройку. |
| `Signing requires a development team` | TARGETS → InteractiveBook → Signing & Capabilities → выбрать Team. |
| Bundle Identifier недоступен | Выполнить setup до первой установки или задать уникальный идентификатор вручную. Не менять идентификатор уже установленного приложения без необходимости. |
| `No profiles for ... were found` | Проверить вход в Apple Account, Team, Automatically manage signing и интернет; впервые запустить на подключённом телефоне через Xcode. |
| iPhone не виден / `device is not available` | Разблокировать, проверить кабель и доверие, дождаться готовности в Devices and Simulators. |
| Developer Mode disabled | Включить режим разработчика на телефоне, перезагрузить и подтвердить включение. |
| iOS новее поддерживаемой Xcode | Обновить Xcode до версии, поддерживающей установленную iOS. |
| Приложение перестало открываться через неделю | Повторно собрать и установить с прежними Team и Bundle ID. |
| Ошибка команды `devicectl` | Нужен современный полный Xcode; воспользуйтесь Run в Xcode. |
| Скрипт не может найти Xcode в нестандартной папке | Запустить `DEVELOPER_DIR="/путь/Xcode.app/Contents/Developer" bash scripts/setup.sh`. |

## Проверить на Mac без телефона

Откройте проект, выберите установленный симулятор iPhone и нажмите Run. Аккаунт и подпись для симулятора не нужны. Если симуляторов нет, установите соответствующую платформу через настройки Xcode.

Для разработчиков: `bash scripts/check.sh` выполняет сборку для симулятора и изолированные проверки WebKit. Это не проверка подписи для физического телефона.


## Готовый IPA для SideStore (для сопровождающего проекта)

В репозитории есть воспроизводимая сборка unsigned Release iPhoneOS IPA. Она не меняет исходный Bundle ID и не устанавливает приложение автоматически:

```bash
bash scripts/build-sidestore.sh agent-artifacts/releases/local/InteractiveBook-sidestore.ipa
```

Нужны настроенный Xcode, Python 3, доступные зависимости Swift Package Manager и проверенные локальные модели Silero (см. `docs/SILERO_BUILD.md`). Если модели отсутствуют или их контрольные суммы не совпадают, скрипт останавливается: неполный нейросетевой голос не включается молча. Для обычной установки из Xcode по инструкции выше можно пользоваться Apple TTS без моделей.

Сборщик создаёт `Payload/InteractiveBook.app/`, исключает служебные AppleDouble-файлы и проверяет arm64/iPhoneOS, plist, исполняемые файлы и обратную распаковку. В базовом plist техническое имя становится `InteractiveBook`; русское название переносится в `ru.lproj/InfoPlist.strings`. Это исправляет обнаруженную ранее передачу кириллицы как `appIdName`. Сам исходный `.app` не меняется.

Рядом сохраняется `.ipa.json` с SHA-256 и результатом проверок. Повторный запуск не перезаписывает старый IPA — задайте новое имя. Это проверка упаковки, а не подтверждение регистрации и установки: SideStore должен переподписать IPA аккаунтом получателя. Проверка непосредственно на его iPhone остаётся отдельным шагом.

Для упаковки уже имеющегося **неподписанного** Release `.app` без пересборки:

```bash
python3 scripts/package_sidestore.py \
  --app build/sidestore-release/Build/Products/Release-iphoneos/InteractiveBook.app \
  --output agent-artifacts/releases/local/InteractiveBook-repacked.ipa
```

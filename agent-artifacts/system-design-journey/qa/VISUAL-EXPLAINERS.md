## Интерфейс

Последовательности читаются по шагам или целиком; сравнения — по схемам либо в режиме «Сравнить». Формулировки различаются, чтобы сравнение моделей не выглядело обязательной последовательностью внедрения. Нет автоматического проигрывания и ограничения времени. Подпись, основной вывод и условия схемы доступны текстом; исходная теория остаётся открытой.

Кнопки имеют min-height44px, нативный клавиатурный фокус и aria-pressed; статус шага объявляется через aria-live. Переключение меняет hidden и состояние существующих элементов, не пересоздавая кнопки. У SVG есть title/desc и уникальные IDs. На узком экране локально прокручивается схема; пояснение переносится по ширине. Для печати показываются все кадры, даже если выбран один шаг.

## Источники и сборка

Два JSON-пакета visual-explainers-a/b.json содержат точные кадры, подписи, условия и места вставки. visual-explainers.js — поведение и генерация интерфейса. build.py проверяет состав, места, режимы, число кадров, SVG allowlist, viewBox и локальные ссылки; ID маркеров изолируются по вставке и кадру. JS и SVG встраиваются в итоговый HTML, внешние библиотеки и сеть для просмотра не нужны.

## Explanations, distractors, WHEN и quality

Все 100 option fields рассмотрены. Distractors отражают профессиональные ошибки, а не карикатуры: локальную выгоду вместо полной, бумажную обратимость вместо проверки, преждевременную уверенность, подмену outcome proxy-метрикой, статический backfill при живых writers, управление ярлыком срочности, чужую BATNA вместо своей, оценку человека без среды, временную экономию вместо recurring затрат, неверный временной горизонт, шумный alert, скрытый scope change, декларативный action item, повторную ручную эскалацию и неконтролируемую метрику PIP.

WHEN проверялся для всего варианта, включая числа, сроки и последствия. Новых самостоятельных логических дефектов WHEN не выявлено.

## Содержательная проверка

Все32briefings прочитаны последовательно: одна компания, исходные500заказов/сутки, явное наращивание ограничений и причинные связи между главами. Восемь паспортов atlas просмотрены; углублённо прочитаны money, collaboration и telemetry. Переносимые механизмы отделены от отраслевых различий.

Выборочно подробно проверены механизмы и расчёты:

- Глава04: условное UPDATE для последнего товара согласуется с READ COMMITTED PostgreSQL; различены потерянное обновление, отрицательный остаток, write skew, повтор всей транзакции и внешний эффект.
- Главы11–12: publisher confirm, consumer ack, routing и внешний эффект различены. Kafka order scoped to partition; exactly-once не распространяется автоматически на банк/SMS. Outbox закрывает локальное двойное сохранение, допускает повтор relay; saga не обещает откат физического мира.
- Глава19: majority пересечение не выдано за достаточное доказательство linearizability; указаны актуальность журнала, term и условия лидерского чтения. Fencing проверяется ресурсом; lease и operation_id закрывают разные гонки. CAP availability не подменена быстрым ответом-ошибкой.
- Глава20:450×1,2=540; ограничение800при мощности1000в исходных единицах оставляет запас при20%росте стоимости;24000/100=240с. RPO0 scoped к отказу одной зоны и работающей синхронной схеме; восстановление требует ключей и проверки инвариантов.
- Глава23:240MB/16MB=15частей;10000×3Mb/s=30Gb/s до overhead. ETag не выдан за универсальный MD5, S3 API не выдан за одинаковую гарантию всех провайдеров; CDN не отменяет авторизацию.
- Главы26–27: retrieval не даёт полномочия, недоверенный документ не является политикой, утверждение операции отделено от её исполнения и повтора; подтверждение связано с точными параметрами и актуальным правом.
- Глава28:320000/15000≈21,33;460000/11000≈41,82;280000/15000≈18,67. Инвестиция80000 при экономии40000/месяц окупается за2месяца при сохранении предпосылок. Учебные ставки названы учебными; исключённые расходы объяснены.

## Интерфейс и безопасность

Статический scan `python3 qa/check_offline.py` проверяет отсутствие внешних render dependencies, inline event attributes, CSS imports и network fetch. Основной текст, SVG, стили и JS встроены; внешние источники открываются по пользовательскому переходу.

Сборщик проверяет allowlist rich HTML и сбалансированность тегов, SVG XML, запрет script/foreignObject/inline events/external refs. SVG ids получают prefix; VM проверяет уникальность HTML/SVG ids каждой построенной главы. В CSS присутствуют minmax(0,…), min-width:0, mobile breakpoint760px и локальный scroll SVG/table/pre. Это проверка паттернов исходника, не подтверждение внешнего вида.

Найденный crash при `{done:null,notes:null,…}` в сохранённом состоянии исправлен автором интерфейса: sanitizer ограничивает chapter IDs, индексы, типы и theme. Повторный VM прошёл. Исправлены prefix SVG ids и сохранение pending позиции до смены главы.
